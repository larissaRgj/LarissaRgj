## 🌟 Projetos em destaque

### 🎮 Laevatein — Fuga de Marte
Jogo de ação e plataforma 2D em pixel art, executado no navegador. Ajude um astronauta a escapar de Marte em três fases, enfrentando inimigos e chefes.

- **Tecnologias:** JavaScript, HTML5 Canvas e CSS
- Três fases, combate, chefes, pontuação e controles para teclado, gamepad e tela sensível ao toque
- [Ver repositório](https://github.com/larissaRgj/laevatein) · [Baixar o jogo (ZIP)](https://github.com/larissaRgj/laevatein/raw/refs/heads/main/LaevateinFinal.zip)

### 🍓 AçaíBom
Sistema web para compra e venda de açaí.

- **Tecnologias:** Java, Spring Boot e MySQL
- Cadastro de clientes e vendedores
- Gestão de estoque em tempo real
- Dashboard financeiro para visualização de faturamento
- Alertas automáticos de produtos e pedidos
- **Código:** [Backend](https://github.com/larissaRgj/rootsacai) · [Frontend](https://github.com/larissaRgj/rootsacai-frontend)
- **Deploy:** [Visualizar projeto](https://astonishing-kangaroo-ad206b.netlify.app/)

### 💰 PocketFinance
Aplicativo mobile para controle financeiro pessoal.

- **Tecnologias:** React Native, TypeScript e Expo
- Cadastro de receitas e despesas
- Organização por mês e ano
- Cálculo automático de saldo
- **Repositório:** [pocketfinance](https://github.com/larissaRgj/pocketfinance)

### 🏥 Gestão Hospitalar
Sistema web para gestão de hospitais e clínicas.

- **Tecnologias:** Node.js, Express, React e MySQL
- Cadastro de pacientes
- Agendamento de consultas
- Gerenciamento de médicos e especialidades
- API REST para consulta e integração de dados
- **Repositório:** [gestao-hospitalar](https://github.com/larissaRgj/gestao-hospitalar)
- **Deploy:** [Visualizar projeto](https://gestao-hospitalar-delta.vercel.app)
